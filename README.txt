Apple Developer Account Manager Desktop 1.0

How to start:
Double click ASC Radar.exe.
If Windows blocks exe files from another computer, use 启动桌面版.vbs or start.cmd.

Portable use:
Copy the whole Apple开发者多账号管理工具-ASC Radar-1.0 folder to another Windows computer.
Do not copy start.cmd alone.

This is a native Windows desktop app built with PowerShell + WPF.
It does not open a browser and does not require Node.js.

Data files:
data/store.json
data/local.key

Real Apple sync requires:
Issuer ID
Key ID
.p8 private key

Do not store Apple ID passwords or verification codes in this tool.
